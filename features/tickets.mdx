The Ticket System provides a complete support solution for Discord servers, allowing users to create private support channels with customizable categories, automatic transcripts, and user feedback collection.

## Overview

BotTroner's ticket system creates private channels for support requests, manages permissions automatically, and generates HTML transcripts when tickets are closed.

## Core Architecture

The ticket system is implemented in the `Tickets` class:


## Setup

### `/tickets setup`

Initialize the ticket system in your server.

**Options:**
- `channel` (optional) - Channel where the ticket creation button will be sent

**Example:**
```
/tickets setup channel:#tickets
```

This creates an embed with a button that users can click to open tickets:

```typescript
// From: src/class/tickets/tickets.ts:32
const ticketMsg = new EmbedBuilder()
    .setTitle('Tickets')
    .setDescription(tDescMsg)
    .setColor(0x00AE86)
    .setFooter({ text: `created by Troner14` })
    .setTimestamp();

const newticket = new ButtonBuilder()
    .setCustomId('ticket-new')
    .setLabel('Crear ticket')
    .setStyle(ButtonStyle.Primary);
```

<Note>
The setup message is persistent - if the bot restarts, it will update the existing message rather than creating a new one.
</Note>

## Creating Tickets

### `/tickets new`

Create a new support ticket manually (alternative to the button).

**Options:**
- `category` (required) - Category ID for the ticket type
- `lang` (required) - Preferred language for support
- `descripcio` (required) - Description of the issue

**Example:**
```
/tickets new category:1 lang:"English" descripcio:"Need help with setup"
```

### How It Works

1. **Validation**: Checks if user already has an open ticket in that category
```typescript
// From: src/class/tickets/tickets.ts:139
const nTickets = await tickets.count({
    where: {
        usrId: interaction.user.id,
        category: categ,
        closed: false
    }
});

if (nTickets >= 1) {
    throw new TicketsErrors("ticketArleadyOpen");
}
```

2. **Channel Creation**: Creates a private channel with appropriate permissions
```typescript
// From: src/class/tickets/tickets.ts:153
const perms: OverwriteResolvable[] = [
    {
        id: interaction.guild!.roles.everyone,
        deny: [permission.ViewChannel, permission.SendMessages]
    },
    {
        id: interaction.user.id,
        allow: [permission.ViewChannel, permission.SendMessages, 
                permission.ReadMessageHistory, permission.AddReactions]
    }
];
```

3. **Role Integration**: Automatically adds users with `ticket:view` permission
```typescript
// From: src/class/tickets/tickets.ts:172
const ticketsRoles = await perfil_permisos.findMany({
    where: {
        permisos: { name: "ticket:view" }
    }
});
```

4. **Database Entry**: Saves ticket to database
```typescript
// From: src/class/tickets/tickets.ts:204
const res = await tickets.create({
    data: {
        guildId: interaction.guild!.id,
        channelId: channel.id,
        usrId: interaction.user.id,
        category: categ,
    }
});
```

## Closing Tickets

### `/tickets close`

Close the current ticket channel.

**Example:**
```
/tickets close
```

### Close Process

When a ticket is closed:

1. **Opinion Modal** (for ticket owner):
```typescript
// From: src/class/tickets/tickets.ts:294
const modal = new ModalBuilder()
    .setCustomId(`ticket-suggest-modal`)
    .setTitle(tModalTitle);

const opinionInput = new TextInputBuilder()
    .setCustomId('opinion')
    .setLabel(tModalInput)
    .setStyle(TextInputStyle.Paragraph);
```

2. **Transcript Generation**:
```typescript
// From: src/class/tickets/tickets.ts:331
const transcript = await this.transcripter.generateTranscript(channel);
const transcriptBuff = Buffer.from(transcript, "utf-8");
const transcriptAtt = new AttachmentBuilder(transcriptBuff, {
    name: `${tickets.guildId}-${tickets.usrId}-transcript.html`
});
```

3. **Database Update**:
```typescript
// From: src/class/tickets/tickets.ts:356
await client.prisma.tickets.update({
    where: { id: tickets.id },
    data: { closed: true }
});
```

4. **Transcript Distribution**:
   - Sent to the ticket owner via DM
   - Sent to configured transcript channel
   - Includes button for feedback (if applicable)

<Tip>
Transcripts are generated in HTML format and include full message history with formatting, attachments, and timestamps.
</Tip>

## Permissions

The ticket system integrates with BotTroner's permission system:

- `ticket:view` - View all tickets (automatically added to ticket channels)
- `ticket:adduser` - Add users to tickets
- `ticket:remuser` - Remove users from tickets

## Error Handling

Custom error class for ticket operations:

```typescript
// From: src/class/tickets/tickets.ts:496
export class TicketsErrors extends Error {
    msg: TranslationKey;
    constructor(message: TranslationKey) {
        super(message);
        this.msg = message;
        this.name = "TicketsErrors";
    }
}
```

**Common error codes:**
- `ticketCategoryError` - Invalid category
- `ticketArleadyOpen` - User already has open ticket
- `ticketChannelError` - Failed to create channel
- `TicketNotChannel` - Command used outside ticket channel
- `ticketSaveError` - Database save failed
