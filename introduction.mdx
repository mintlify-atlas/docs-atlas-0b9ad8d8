# Welcome to BotTroner

BotTroner is a sophisticated Discord bot built with modern web technologies, designed for scalability and high performance. Leveraging the speed of the Bun runtime and the type safety of TypeScript, BotTroner provides a complete solution for managing virtual machines, handling support tickets, and distributing announcements directly from Discord.

## What is BotTroner?

BotTroner was created to solve the problem of managing virtual machines comfortably for small hosting companies directly from Discord. It also adds a complete ticket system to manage incidents and an announcement distribution system for broadcasting updates across multiple channels.

## Technology Stack

BotTroner is built with cutting-edge technologies:

- **Runtime**: [Bun](https://bun.sh) - An extremely fast all-in-one JavaScript runtime
- **Language**: [TypeScript](https://www.typescriptlang.org/) - For static typing and better developer experience
- **Framework**: [Discord.js](https://discord.js.org/) v14 - For interaction with Discord's API
- **Database**: [Prisma](https://www.prisma.io/) ORM with MariaDB - Robust data management
- **Logging**: [Pino](https://getpino.io/) - Structured logging ready for production
