## Overview

`VirtualizationManager` is the central manager for virtualization operations. It handles multiple virtualization providers (currently Proxmox, with support for future providers like VMware, Hyper-V, OpenStack) and manages panel connections, VM operations, and permissions.

**Source:** `src/class/virtualization/VirtualizationManager.ts`

### executeVMAction()

Executes an action on a VM with permission checking and audit logging.

```typescript
async executeVMAction(
  panelId: number,
  action: VMAction,
  userId: string,
  guildId?: string
): Promise<ManagerResult<VMActionResult>>
```

<ParamField path="panelId" type="number" required>
  Database ID of the panel
</ParamField>

<ParamField path="action" type="VMAction" required>
  Action to execute
  
  ```typescript
  {
    vmId: string;
    type: 'start' | 'stop' | 'restart' | 'shutdown' | 'reset';
  }
  ```
</ParamField>

<ParamField path="userId" type="string" required>
  Discord user ID performing the action (for permission checks)
</ParamField>

<ParamField path="guildId" type="string">
  Discord guild ID for context
</ParamField>

<ResponseField name="data" type="VMActionResult">
  Result of the action execution
</ResponseField>

**Workflow:**
1. Checks user permissions via `checkVMPermission()`
2. Connects to the panel
3. Executes the action through the provider
4. Logs the action result to database
5. Returns success or error response

**Example:**
```typescript
const result = await manager.executeVMAction(
  panelId,
  { vmId: '100', type: 'start' },
  interaction.user.id,
  interaction.guildId
);

if (result.success) {
  await interaction.reply('VM started successfully');
} else {
  await interaction.reply(`Error: ${result.error}`);
}
```

## Complete Example

```typescript
import { VirtualizationManager } from '@class/virtualization/VirtualizationManager';
import { prisma } from '@class/prismaClient';

const manager = new VirtualizationManager(prisma);

// Add a new Proxmox panel
const addResult = await manager.addPanel(
  guildId,
  'Main Proxmox Server',
  'proxmox',
  'https://pve.example.com:8006/api2/json',
  {
    username: 'admin@pam',
    tokenId: 'automation',
    tokenSecret: process.env.PROXMOX_TOKEN
  },
  true
);

if (!addResult.success) {
  console.error('Failed to add panel:', addResult.error);
  return;
}

const panelId = addResult.data!.id;

// List all VMs
const vmsResult = await manager.listVMs(panelId);
if (vmsResult.success) {
  console.log(`Found ${vmsResult.data?.length} VMs`);
}

// Execute action with permission check
const actionResult = await manager.executeVMAction(
  panelId,
  { vmId: '100', type: 'start' },
  userId,
  guildId
);

if (actionResult.success) {
  console.log('VM started successfully');
} else if (actionResult.errorCode === 'AUTHENTICATION_FAILED') {
  console.log('Permission denied');
}

// Get guild statistics
const stats = await manager.getStats(guildId);
console.log(`${stats.data?.runningVMs} of ${stats.data?.totalVMs} VMs running`);
```
